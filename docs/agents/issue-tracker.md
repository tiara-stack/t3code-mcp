# Issue tracker: Linear

Issues and specifications for this repo live in Linear. Use the Linear MCP for
issue operations.

## Repository routing

- Team: `tiara-stack`
- Canonical identifier: the full Linear issue URL
- Resolve, read, and update issues using their full Linear URL.

## Operations

- Create issues in the `tiara-stack` team through Linear MCP.
- Read issue details, comments, labels, status, and assignee through Linear MCP.
- Add comments, labels, assignments, and status changes through Linear MCP.
- When a skill says to publish to the issue tracker, create or update the
  relevant Linear issue.
- When a skill says to fetch a ticket, use its Linear URL with Linear MCP.
